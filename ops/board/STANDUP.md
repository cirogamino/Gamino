# STANDUP — append only

Every seat posts its Report Block here each standup. Never edit or delete another
seat's entry. Newest at the bottom.

Format:

```
--- H<hour> | <SEAT> | <timestamp> ---
SEAT:
CYCLE:
STATUS:
NOW:
DONE:
NEXT:
NEED:
BLOCKED:
CONFIDENCE:
KILL SIGNAL:
```

Cross-lane requests go here too, one line, addressed by seat:

```
PROPOSAL: @<SEAT> — <the change you want, in one line>
RESPONSE: @<SEAT> — ACCEPTED | REJECTED (<reason>)
```
